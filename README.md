# Dan Koe Brain

Kevin Shu · AI Practice #006 · 精简公开版

一套独立制作的 AI 阅读与决策辅助流程，围绕写作、专注、个人成长和一人业务讨论，把有来源的观点转换为可检查的小实验。

## 使用

将整个文件夹交给能读取 Markdown 的 AI 助手，先读取 SKILL.md，再提供你的问题及相关来源。示例：请根据我提供的文章，区分作者观点与针对我情况的推演，设计一个一周内可以验证的写作实验。

需要能够读取用户提供材料的 AI 环境；浏览网页为可选能力。无法读到原文时，流程要求说明限制。本包没有脚本、遥测、自动更新或投递功能；服务费用与资料保存取决于所用平台。

## 包含与不包含

公开包只包含流程说明和来源入口，不含原始 ZIP 的 168 份字幕、168 份摘录与 brain.md。它不具备完整本地资料包的离线检索范围，也不宣称覆盖作者全部作品。
